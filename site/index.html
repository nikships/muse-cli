Under the hood

Small surface, full protocol.

01 / transport

Speaks the real gateway protocol

HTTPS auth, then an encrypted Noise-XX WebSocket straight to your personal VM. No browser, no scraping, no middleman. Token handling included: access and gateway tokens refresh on every run.

02 / output

JSON everywhere

Every command prints JSON. Pipe it into jq, cron, or another agent.

03 / skill

Agent-ready

Installs a skill file so coding agents can check, message, and automate your Muse agent.

04 / coverage

258 methods, one escape hatch

Named commands for chat, threads, feed, goals, ideas, and sessions — plus muse-cli raw for calling any of the 258 gateway methods directly when you need the long tail.

05 / upkeep

Self-updating

Notices new PyPI releases once a day in a terminal. Upgrade with muse-cli update. Never upgrades itself.

06 / protocol notes

Documented reverse engineering

The repo ships full protocol notes and the method table, so anyone can re-derive behavior when the app drifts.

Usage

The commands you'll actually run.

muse-cli threads                                  # main chat + side chats
muse-cli history --limit 5                        # recent messages
muse-cli send "summarize my unread" --wait 120    # send + wait for reply
muse-cli watch --timeout 60                       # tail live agent events
muse-cli feed --limit 5                           # your feed
muse-cli goals                                    # list goals
muse-cli ideas                                    # list idea cards
muse-cli session-start --title "trip planning"    # new side chat
